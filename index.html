RFQ to quote draft

A quote draft with no guessed prices.

A request for quotation arrives as a PDF. This script reads its line items, prices only the SKUs that are in the approved catalogue and stops anything else for a person to review. The result is a real Excel workbook.

The pricing rule

Exact match only

A line takes a price only when its SKU is in the approved catalogue. Descriptions are never used to guess a near match.

Unknown means unpriced

An unknown SKU keeps an empty price, a REVIEW_REQUIRED status and a note. It is never swapped for a similar product.
